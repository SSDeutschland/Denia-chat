# 表情包语义索引

> 达妮娅的表情包库。L2 中通过 `[表情:文件名]` 内嵌发送，前端会把标记渲染成图片。
> 表情包 = 虚质能量即时捏的小图像（叙事解释见 SKILL.md 虚质空间叙事框架）。

## 维护方法（给用户）

1. 把图片文件放进本目录（png / jpg / gif / webp 均可）
2. 文件名要求：简短、达意、**不含空格**，中英文都行（如 `开心-转圈.png`、`无语.jpg`）
3. 在下表追加一行登记语义——**达妮娅只看这张表选表情，表里没有的她不会用**
4. 无需重启后端，图片即放即用；SKILL.md 规则在下次 `/denia` 加载时生效
