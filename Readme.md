# Denia — 达妮娅

> 《鸣潮》角色达妮娅的 AI 化身——带完整人格、情绪、记忆与同生活能力的角色扮演助手。
> 非官方同人项目，与库洛游戏无关。角色版权归原作所有。

她不是一个套着角色皮的聊天机器人。她有 8 维度人格模型驱动的思维方式（L1 内心独白 / L2 对话分离）、会流动有记忆的情绪系统、跨会话的长期记忆（她会记得你上周说过的事）、自己的看法库和想法池——你不说话的时候，她在虚质空间里也有自己的生活。

## 三分钟上手（Windows）

**什么都不用装版（便携包）**：从 [Releases](../../releases) 下载 `Denia-portable-*.zip` → 解压 → 双击 `首次运行-初始化.bat` → 双击 `启动达妮娅GUI.bat` → 浏览器里点 ⚙ 填入模型 key（见下）→ 开聊。

**会装 Python 版（git clone）**：

```bash
git clone https://github.com/SSDeutschland/Denia-chat.git
cd Denia-chat
```

然后双击 `首次运行-初始化.bat`（把文件里的路径占位符替换成你的实际位置，只跑一次）→ 双击 `启动达妮娅GUI.bat`（首跑自动建环境装依赖）→ 浏览器自动打开 http://127.0.0.1:8765。

**终端党**：在本目录运行 `claude`，输入 `/denia`。

## 钥匙：模型 API

她的大脑需要一个大模型驱动，key 你自己准备（按量付费，日常聊天一天几毛钱量级）：

- **推荐新手**：DeepSeek（[platform.deepseek.com](https://platform.deepseek.com) 注册充 5 块够用很久），GUI ⚙ 设置里加预设：base_url `https://api.deepseek.com/anthropic`，model `deepseek-v4-flash`
- **想要识图**：GLM 智谱（[open.bigmodel.cn](https://open.bigmodel.cn)），预设里 `vision: true`
- 详细教程：**[docs/配置-API钥匙.md](docs/配置-API钥匙.md)**——也可以直接把那篇文档丢给任意 AI，让它带你配

## 她能做什么

| 能力 | 默认状态 | 配置 |
|------|---------|------|
| 三层人格对话 + 长期记忆 + 情绪系统 | ✅ 开箱即用 | 无需配置 |

## 她的记忆结构（隐私说明）

```
denia/
├── 共享/    角色本体：人设、游戏剧情记忆、看法库、表情包 —— 本仓库公开的就是这部分
├── 私有/    她与你的记忆：用户档案、每次对话归档、情绪状态 —— 只存在你的电脑上
└── 缓冲/    QQ 分身专用的隔离区（物理隔离，分身碰不到你的私人记忆）
```

你和她聊出的一切都在你自己硬盘的 `denia/私有/` 里（且已被 gitignore），不会因为 git 操作泄漏。
